Jevibe Check privacy policy

Effective September 17, 2026

Jevibe Check labels the tone of posts and drafts using TypeSafe's Jev API. It can blur or collapse posts that match your filter rules. Labels are not posted to the social network. Scripts on the page can read displayed labels, scores, and custom classifier names.

Text sent to TypeSafe

When you supply an API key and enable live classification, unpublished draft text is sent to TypeSafe after a short pause in typing. When you enable labels for viewed posts, visible post text is sent from supported feeds, search results, and threads. Both features are initially enabled, but requests require a saved API key and at least one enabled classifier.

Requests include the text being classified, a description of whether it is a draft or published post, and enabled classifier questions and possible labels, including custom definitions. Your API key is sent in the authentication header over HTTPS to api.typesafe.ai. TypeSafe also receives normal connection metadata, such as your IP address.

The extension does not attach images, videos, surrounding conversations, account profiles, cookies, or page URLs to classification requests. Text may itself contain links, names, personal information, or sensitive content. On custom sites, the selectors you configure determine which text is collected.

Requests go directly to TypeSafe. The extension developer does not operate a proxy or receive a copy. TypeSafe's own terms and data policies govern its processing, retention, and deletion of submitted data; Jevibe Check does not control them or promise that TypeSafe retains no data. Review those policies through your TypeSafe account before use.

Data kept on your device

Chrome's local extension storage holds your API key, classifier definitions, switches, filter rules, permitted sites and selectors, pricing preferences, and aggregate usage statistics. These are not synced through Chrome Sync or sent to the developer. The key is restricted to trusted extension contexts, but local storage is not an encrypted credential vault.

Usage statistics contain counts, token totals, estimated cost, and the start date of tracking. They do not contain draft text, post text, browsing history, or the API key.

Viewed-post text and results can be cached temporarily in tab memory and in the background service worker to avoid duplicate requests. Tab caches end on reload or close; the background cache ends when Chrome stops the worker. Settings changes clear classification caches. The extension does not write post text, drafts, or classification history to persistent storage.

Site access

Jevibe Check runs on Bluesky. Other HTTPS sites require you to add their domain and grant Chrome's permission. The ability to request additional sites does not grant access to every website. Site origins are used locally to check permission and select detection rules. The extension does not collect a browsing-history log or monitor unrelated activity. Only add sites you trust: page content can trigger classification requests and consume your API credits.

Your controls and deletion

Disable live classification or viewed-post labels in settings to stop the corresponding requests. Removing your API key and saving stops both. A request already received by TypeSafe cannot be recalled. Remove an added site to revoke its access. Filters are off by default.

You can edit or delete your key and custom settings in the extension. Clear stats resets local usage totals and their tracking date without removing your key or settings; it does not change TypeSafe billing. Uninstalling the extension removes its local extension storage; closing its social tabs clears their in-memory data. Removing local data does not delete data already received by TypeSafe. Use TypeSafe's account or support channels for its retention and deletion requests.

Limited use

Jevibe Check uses data only to provide the labels, filters, settings, and usage information described here. Its use and transfer of user data comply with the Chrome Web Store User Data Policy, including the Limited Use requirements. The extension has no advertising, analytics, tracking service, sale of personal data, or developer-operated data collection.

Policy updates

Changes will be reflected in this policy and its effective date. For questions about the extension, use the developer contact provided with its distribution or Chrome Web Store listing. For TypeSafe's handling of API requests, contact TypeSafe.
